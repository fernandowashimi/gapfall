# Verified Google identity, no Player database

Versus identity is optional Google in this browser, not an account. A Match may show a name and image only after a Google ID token is verified; otherwise that side is an anonymous Opponent. There is no Player table, Match history, or ladder — ranked later must introduce a store if it needs one.

Required sign-in, a server-side Player record, and unverified client-supplied labels were rejected: the first reverses anonymous Matchmaking, the second is an account system this pass does not have a job for, and the third is a costume rather than identity.
