# Main Menu and matchmaking UX

Type: grilling

## Question

The Main Menu gains Versus beside Single Player (today’s Play). Clicking Versus shows matchmaking loading while it searches the public queue. What does that shell actually say and do?

Grill, one question at a time:

- Exact button labels on the Main Menu (Portuguese overlay style, matching the existing Main Menu)
- What the matchmaking loading state shows (copy, spinner, estimated wait — or none)
- How the player cancels search and returns to the Main Menu
- What happens if the queue stays empty (wait forever, timeout copy, still just loading)
- Where the local high score sits now that Single Player and Versus share the Main Menu

Recommend: labels Single Player and Versus; a simple loading state with cancel via Back/Esc to the Main Menu; wait indefinitely with no timeout theatre; high score stays on the Main Menu as the Single Player record.
