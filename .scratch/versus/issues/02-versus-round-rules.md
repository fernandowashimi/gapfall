# Remaining Versus Round rules

Type: grilling

## Question

The Versus Round’s unique rules are mostly locked (constant Base Fall Speed, no score, one extra Generated Line stacked packed above the opponent’s current top per removed line, own board only). What still needs a decision before the spec can state the Round itself?

Grill, one question at a time:

- After matchmaking finds an opponent, do both players share the same preparation countdown before Playing Time starts?
- Can those sent extra Generated Lines be Reinforced Lines (same roll as cadence spawn), or are they never reinforced?
- Does the Versus HUD show anything besides the board (Playing Time, opponent-alive, lines sent), or is it board-only?
- Is each player’s empty-slot RNG independent?

Recommend: shared three-second preparation after match found; sent Generated Lines use the same reinforce roll as cadence spawn (they are Generated Lines); HUD is board-only; RNG is independent per player.
